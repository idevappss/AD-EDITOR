# Archetypes and fallback palettes

Reference for motion-graphics-director. Use fallback palettes only when the user supplies no brand tokens.

## Archetypes

| Archetype | When | Signature moves |
|---|---|---|
| Designer showreel (0:10–0:30) | Show off craft, brand energy | Dark open on a single dot or line, hard cut to a giant word on a solid color field, easing-curve diagram, dot/particle grid, 3D extruded cube wave, repeated-word wallpaper, logo end |
| SaaS / app launch (0:20–0:60) | New product, feature, offer | One-line pain hook, a word struck or transformed, data proof (grid filling, counter 31% to 94%), logo reveal, UI cards tilted in 3D, CTA |
| Illustrated narrative (1–5 min) | Story, timeline, thought piece | Recurring character, line art that fills with color, editorial serif on paper texture, captions synced to VO |
| Product hero (0:15–0:30) | Physical or single hero product | Object centered on white, slow rotate, one stat callout ("65 cm."), tagline with one colored word |
| Mascot-led | Friendly consumer brand | Same character anchors every beat; the color field changes behind it each beat |
| Hybrid footage + motion | Ads, UGC, service explainers | Real or AI footage plus bold type overlays, 3D cutaways, talking head with cutaways in the top half |
| Vertical app update (9:16) | Reels, TikTok, Stories | Phone mockup centered, 2-line headline above, UI states change on the beat |

## Fallback palettes

- **Bold showreel:** near-black #0E0E10, hot orange #F0592A, cobalt #2A3BFF, cream #F2EEE6.
- **Launch page:** warm off-white or cream background, soft pastel gradient blobs, one accent color for the key word.
- **Dark premium:** black plus a single glow color (orange, violet, or neon lime) with bloom.
